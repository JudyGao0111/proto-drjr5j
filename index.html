Prototype 示範版可點擊操作

新北市全民運動課程報名系統

整合多個計畫（運動熱區、女性常態運動、運動i臺灣…）與多家課程廠商的報名前後台。所有資料皆為示範資料，存在您的瀏覽器中，隨時可重置。

📱

前台｜民眾端

手機、電腦皆可操作
  • 首頁、依行政區找課程、搜尋篩選
  • 課程詳情與報名須知
  • 會員註冊／登入（身分證字號＋驗證碼）
  • 報名流程（含長期班每年 2 班限制、候補、審核）
  • 會員中心：我的課表、QR 簽到簽退、體適能前後測、問卷、通知、獎勵與目標
🖥️

後台｜體育局／廠商端

建議以電腦操作；右上可切換身分
  • 儀表板（跨計畫、跨廠商總覽）
  • 班級管理、場次、改期／停課＋通知
  • QR 簽到、紙本備援補登、報名審核與候補遞補
  • 體適能匯入（局端格式、身分證比對）
  • 成果統計報表、滿意度統計、新北幣名單匯出、通知與公告

建議的示範順序（約 5 分鐘）

  1. 前台：點「使用示範帳號登入（陳美玲）」→ 看「會員中心」的獎勵與目標。
  2. 前台：找課程 → 報名「肌力雕塑班」成功 → 再看「太極養生班」，會被「每年最多 2 班」擋下。
  3. 前台：會員中心 → 簽到簽退 →「掃描 QR Code 簽到」（模擬）。
  4. 後台（切換成「廠商：飛躍運動企業社」）：場次與簽到 → 看到該學員已簽到；對下一堂「改期／停課」並通知學員。
  5. 後台：體適能匯入 → 使用範例檔 → 確認匯入 → 回前台「我的體適能」看到本期前測。
  6. 後台（切回體育局）：成果統計報表（局端格式）、滿意度統計、新北幣名單匯出。

💬 想調整畫面？直接在畫面上回報

前台、後台、本頁右下角都有「回報修改」按鈕，點開後：

  1. 系統自動帶入修改位置（前台／後台）、頁面名稱、裝置（手機／電腦）、檢視身分（體育局／廠商）。連目前開著的彈出視窗也能辨識。
  2. 按「🎯 在畫面上點選位置」，再點一下要改的地方，會自動寫出「【按鈕】『我要報名』，在『報名名額』區塊」這類描述。
  3. 填「改什麼」「為什麼」，選優先順序（必改／想要／先不改只討論）；可選圖或直接 Ctrl+V 貼上截圖（Win+Shift+S 截圖）。
  4. 到「我的回報清單」按 ⬇ 匯出 Excel，欄位與《Prototype修改需求回報表.xlsx》相同，圖片會放在「截圖」工作表。把檔案放進專案資料夾，告訴我檔名即可。

回報清單只存在這台電腦的瀏覽器，與示範資料的「重置」互不影響；匯出前請先不要清除瀏覽器資料。

需求對照（會議 2026/11/16 ＋ 網頁建置需求說明）

需求在原型中的呈現
前台：民眾報名、依行政區看課程前台首頁「依行政區找課程」、課程列表篩選、報名流程
會員以身分證字號註冊、同意鈕、Email／簡訊驗證註冊時以簡訊或 Email 驗證一次（示範碼 123456），同意條款可點開閱讀；登入為「帳號（身分證字號）＋密碼」，含忘記密碼流程；修改手機／Email 需重新驗證
首頁輪播 Banner、最新消息（含圖片與附件）前台首頁 Banner 與最新 5 則、最新消息專屬分頁；後台「前台內容管理」僅最高管理員與局端帳號可上架，廠商無權限
課程列表可切換呈現方式前台找課程：卡片／條列切換
審核備註（僅內部可見）後台報名名單與審核新增「備註」欄，民眾看不到，匯出名單時一併帶出
開放所有民眾報名，不限新北市民或戶籍報名頁與須知皆不檢查戶籍；僅女性計畫限女性
24 堂帶狀課每人每年最多報 2 班（以班為單位）班級設定有「計入長期班限制」屬性；前台第 3 班被擋，並顯示已報 n／2 班
各班自訂報名期間、一年皆可開班班級管理：報名開始／截止、堂數、星期、名額可自訂
N 家廠商各自上架、編輯課程；不限家數後台右上切換廠商身分，只看到自己班級；體育局看全部
臨時異動須通知學員（Email／簡訊）場次「改期／停課」與「通知與公告」，含簡訊額度預估；前台「通知」同步可見
變更須於活動前 2 週函報機關（不可抗力除外）改期視窗依距離天數提示，未滿 2 週需勾選機關同意或選擇不可抗力原因
QR Code 簽到簽退＋紙本備援，廠商可後台補登前台模擬掃描；後台 QR 視窗、出缺席登載、紙本簽到表列印
出席率對廠商很重要，可即時查看後台儀表板、場次出席數、出席率總表
體適能前後測；格式以局端為準，匯入一次、以身分證比對後台體適能匯入（一般／銀髮兩種欄位格式，驗證重複與格式錯誤）；前台前後測比較
滿意度問卷全市統一、由體育局提供前台依「附件 3」問卷填答；後台依「附件 4」統計格式呈現與匯出
結案匯出出席率、報到率、問卷；成果報告統計表成果統計報表依局端「總體統計表」格式（年齡統計表、各場次人數統計表）並可匯出 CSV
新北幣不介接，系統匯出符合名單新北幣名單：設定條件、篩選、匯出 CSV 與匯出紀錄
會員可看歷次體適能、已報課程、獎勵與目標前台會員中心總覽、我的課表、我的體適能
民眾端手機可操作；後台以電腦為佳前台響應式；後台為桌面版面（手機可瀏覽）

尚未定案的事項（原型中以「待確認」標籤標示）

以下為會議紀錄「待確認」項目，原型僅以示意方式呈現，需體育局確認後調整。

  • 待確認 #5 簡訊平台與簡訊量：是否有體育局自有簡訊平台，或由承辦廠商協助洽合作簡訊商（預先儲值扣抵）。
  • 待確認 #7 新北幣於招標文件的載明方式；系統以匯出名單配合。
  • 待確認 #9 問卷填答時機（報名後、上課至某階段、最後一堂），以及最後一堂請假者的處理。原型於班級設定提供三種選項。
  • 待確認 #10 獎勵發放條件：出席率門檻、體適能進步幅度的換算方式（第一次測得較差者較易進步，需審慎設計）。
  • 待確認 #11 連結「我的新北市 APP」「新北運動聚點 FB」、發布消息：原型放置了頂部連結與後台發布公告，實際網址待提供。
  • 其他：上線時程與分階段方案、網址方案、無障礙等級、金流（初步認知為免費、不含金流）。

Prototype 僅供需求溝通與流程確認：QR Code 為示意、驗證碼為固定值、體適能匯入以範例資料示意；非正式系統。
